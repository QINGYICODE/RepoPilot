### 记录 009：D3 文件、历史与证据索引（已完成）

**实现**：JavaParser 类型/方法切分、带行号的安全 POM XML 解析、YAML 配置块与补充窗口；保留源 blob、完整 SHA、所属快照和展示内容哈希。复用与路径无关的内容缓存，并保留解析警告。

遍历指定 SHA 的可达历史，存储 commit、父提交与实际 diff hunk；历史事实与快照成员关系分开保存，避免每个快照重复复制相同历史。MySQL 英文/中文 ngram 全文索引与字面检索结合；分页游标绑定查询、快照和检索方式。文件范围、证据详情均检查仓库和快照。

**发现与修复**：集成测试发现重命名后的内容缓存携带旧路径，改为缓存与路径无关的切分信息；JGit 合成 FileHeader 缺少完整 hunk 字节，改为解析实际 patch，并升级索引至 v2.2。中文查询与 ASCII SHA 列比较引发排序规则错误，改为仅对完整 SHA 查询该字段。连接统一 UTC，并验证真实提交 epoch。

**最终真实索引**：141 个文本文件、761 个可达提交、8,423 条 DIFF 证据（含纯元数据记录）、10,135 条总证据、9 个 Maven 项目节点；历史遍历完整。整体覆盖仍为 PARTIAL：外部 parent/BOM、profile、超限 diff、长 hunk 截断与脱敏均明确标记。索引构建阶段记录为 15,980 ms，不含下载和发布。

## 五、公开仓库接入与网络恢复（2026-11-04）

用户反馈接入其他仓库经常失败，并指定用当前 RepoPilot 项目验证。发现默认允许列表阻止新仓库、前后端超时不匹配，以及当前环境代理出口匿名额度耗尽。新增管理页面显式授权与可恢复连接任务，后台核验公开属性和稳定 githubId，再自动导入默认分支。模型仍只能读取任务绑定的已授权仓库，撤销授权后工具读取同样被拒绝。

GitHub API 加入操作总期限、分类错误、限流恢复时间、元数据缓存及网络故障代理降级；显式代理不会被自动绕过，也不通过更换出口规避限流。JGit 使用相同路由规则；已就绪索引可直接复用。前端显示连接与索引的不同阶段，支持刷新恢复和失败重试，隐藏不属于当前仓库的示例 SHA。

真实导入进一步发现 RepoPilot 没有根 pom.xml、后端构建位于 backend/，原解析器因此产生 NO_MAVEN_ROOT。新增无根 POM 时的子目录构建发现，保留实际模块路径；有根构建时继续只分析声明的 reactor。索引版本升为 v2.3，防止复用旧的空模块图。已验证三项真实依赖新增影响 backend 服务，以及 IMPECCABLE_HOME 对应的历史修复 bf9c07f；外部父模型与 BOM 不会据此视为已解析。

已在 localhost MySQL 和真实浏览器验证 RepoPilot 接入、固定 SHA 导入、代码检索、刷新恢复及手机布局。首次导入暴露根目录没有 pom.xml 时漏掉 backend 模块的问题，作为独立索引修复处理。详细真实依据与复现入口见 [仓库接入验收](verification/仓库接入验收.md)。README 继续只介绍能力与使用方法。

真实模型首次在最终选择引用时超时；第二次同轮调用业务候选与辅助检索后，选择了辅助证据 ID，被门禁拒答。保留这些失败后，增加一次受预算控制的引用纠正：只有引用确实在本次任务发放、但不属于业务结论时才允许纠正；伪造/跨范围 ID 仍立即拒答，重复错误仍拒答，不增加工具调用或重置计数。提示版本更新为 repo-agent-v2；另过滤 commit、diff 等请求词，避免把提问措辞当作告警特征。最终 58 项单元测试与 17 项本机集成通过，4 项外部检查按配置跳过。真实模型复测两类业务均 EVIDENCE_VERIFIED，每条各 2 次模型、1 次工具，无工具执行失败；这仍是烟测，不是固定评测集的失败率结论。

## 六、版本选择与历史任务恢复（2026-11-04）

发现索引升级后同一 SHA 重复显示，且从默认 PetClinic 页面打开 RepoPilot 历史任务时，只恢复了结果，没有同步恢复表单范围。新增默认版本去重与新索引优先，明确指定旧快照的链接继续保留原范围。已就绪提交再次被选中时同步更新 activeSnapshot，无需重新抓取；切换仓库时过期请求不再覆盖版本列表。

结果持久化增加服务端 scope，保存仓库、固定版本、任务、模块、部署 SHA 与脱敏问题，取消和拒答也保留；历史无 scope 的 JSON 继续兼容。浏览器回归实际验证跨仓库恢复、原问题与模块/部署版本、刷新、旧链接及手机布局，模型调用为 0。补齐前端四项版本选择回归和数据库兼容、脱敏与缓存选择检查。

范围审查还发现 Windows 路径正则会将 https:// 中的 s:/ 当作本地盘符，错误拒绝同仓库链接。改为明确识别 GitHub 仓库身份，允许同仓库链接，继续拒绝其他仓库、路径与越权指令，并增加独立回归。
