## 复现命令

准备完整 JDK 21 和本机 MySQL 8+，填写 `.env` 并创建 `repopilot` 空库后，在项目根目录执行：

```bash
python3 scripts/dev.py backend-check
python3 scripts/dev.py mysql-test
python3 scripts/dev.py live-llm
python3 scripts/dev.py dependency-tree
cd frontend
npm ci --ignore-scripts
npm run build
```

执行时如需指定 JDK 或 Maven 缓存，通过 `JAVA_HOME` 和 `MAVEN_REPO_LOCAL` 环境变量设置。普通构建不使用真实模型，`live-llm` 才会显式调用供应商服务。

本次完整验收实际使用 `live-llm` profile，包含全部单元和集成测试；其他入口用于分层定位。原始运行日志保留在本机被忽略的 `.local` 和 `backend/target` 中，公共记录不包含模型密钥、数据库密码或供应商地址。
