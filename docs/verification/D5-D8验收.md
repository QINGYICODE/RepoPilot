## 后端结果与复现

```bash
python3 scripts/dev.py agent-check
```

该命令要求先导入上述三个完整 SHA 的 READY 快照，并配置 DB 与 LLM。其余五项历史候选均属于知识版本可达历史，不需要逐一新建快照。首次准备仓库可在仓库页面登记 spring-petclinic/spring-petclinic-microservices，再同步 SHA；同一 SHA 已就绪时直接复用，不重新拉取。

结果：43 项单元测试、15 项集成测试通过；1 项真实仓库重新导入测试按配置跳过，使用已有真实快照。真实模型能力探针、SDK 协议、五个修复候选、两个真实模型业务任务和本机 Git/HTTP/MySQL 回归均执行。

两条业务烟测均返回 `PARTIAL / EVIDENCE_VERIFIED`：静态 Maven 覆盖有限，告警也缺少事故确认链，因此不提升成完整确定结论。依赖任务输入/输出 token 为 2,458/269、约 9.35 秒；告警为 3,134/457、约 10.52 秒。每条各 2 次模型、1 次工具，均无执行失败或参数拦截。token 为供应商报告值，不是估算。

初测曾因模型反复读取已核验原文触发单工具预算；FINALIZE 阶段关闭额外工具后正常收敛。另一次验证因旧预览后端启动回收另一进程任务失败，随后增加 V4 实例归属与 45 秒租约、15 秒续租，并通过回归。失败与后续修复均保留于本机日志及开发记录。

**这些样本不足以证明失败率从 18% 降至 4%。** 执行失败率口径为 `failedToolCalls / executedToolCalls`；参数/权限拦截、缓存、无命中与任务成功率分别报告。固定 50 条样本、同模型和提示版本的前后对照尚未完成。

## 网页复现

```bash
python3 scripts/dev.py agent
cd frontend
npm run dev
```

首页 `http://127.0.0.1:5173/` 提供任务、仓库、模块和版本选择，再输入问题。工具完成事件每秒轮询，刷新使用 URL 中的 run ID 恢复；未实现 SSE/token 流，不展示模型私有推理。

浏览器烟测使用独立临时安装，不增加产品运行依赖：

```bash
npm install --prefix /tmp/repopilot-browser playwright@1.64.1
PLAYWRIGHT_BROWSERS_PATH=/tmp/repopilot-browser-binaries /tmp/repopilot-browser/node_modules/.bin/playwright install chromium
PLAYWRIGHT_MODULE=/tmp/repopilot-browser/node_modules/playwright PLAYWRIGHT_BROWSERS_PATH=/tmp/repopilot-browser-binaries node scripts/preview-smoke.cjs
```

该脚本会调用真实模型，需要上述准备好的快照。覆盖依赖分析、证据查看、刷新恢复、告警候选、无证据拒答、越界/其他仓库拒答、390px 移动端布局与浏览器运行时异常检查。页面截图保存到未跟踪的 `.local/analysis-preview.png`、`.local/incident-preview.png` 和 `.local/analysis-mobile.png`。

WSL 挂载目录的旧 Vite 进程可能未收到文件变更事件，导致浏览器仍显示旧首页；本次重启并用 `CHOKIDAR_USEPOLLING=true npm run dev` 验证新版页面。选择框补充明确的无障碍名称，以便可靠定位与键盘/读屏使用。
