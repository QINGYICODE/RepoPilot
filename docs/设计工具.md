## impeccable 加载器修复

原命令退出码 127：官方加载器默认尝试写入 `/home/wen/.impeccable/bin/0.1.18`，该目录在当前工作区权限之外。技能文件存在，但引擎尚未安装。

修复使用加载器原生支持的 `IMPECCABLE_HOME`，将缓存放入工作区可写的 `.local/impeccable`，不改变 HOME，也不修改第三方加载器、不跳过下载校验。官方引擎 0.1.18 下载后经技能自带校验清单验证，`engine-probe` 返回 `impeccable-engine 0.1.18`，上下文命令退出码 0。

项目提供包装脚本，默认使用 `.local/design-skills/impeccable` 中的技能，并保留环境变量覆盖能力：

```bash
scripts/impeccable.sh engine-probe
scripts/impeccable.sh context --target frontend/src/views/AnalysisView.vue
scripts/impeccable.sh detect --json frontend/src
```

技能目录需包含 `SKILL.md` 和 `scripts/impeccable`。本机已缓存官方 `plugin/skills/impeccable` 的内容；新环境可把该目录复制到上述位置，或设置 `IMPECCABLE_SKILL_DIR` 指向已安装的技能。引擎、技能缓存及原始输出位于被 Git 忽略的 `.local`，不把第三方可执行文件提交到项目。首次下载仍需要网络；后续加载直接使用已校验的缓存。

上下文输出中的“缺少 PRODUCT.md / DESIGN.md”属于项目资料状态，而非加载器故障。本次按已确认的产品需求和实际实现补充这两个文件，不记录未经确认的产品能力。
